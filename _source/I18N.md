# Novalan site — seven-language specification

The original site advertised seven languages in its menu but only ever shipped two; the other five
links pointed back at the English page. This build ships all seven for real.

**Translation, not authorship.** Every page in every language says exactly what
`_source/CONTENT.md` says — no more, no less. Spanish is the source of truth (it is the company's
own language); English is the cross-check. If ES and EN disagree, CONTENT.md records which reading
is correct and why. A translator who cannot render a sentence faithfully must flag it, never
paraphrase around it and never drop it.

### File map — memorise the one irregularity

Spanish sits at the root with Spanish filenames. **Every other locale uses the same five English
slugs inside its own folder.** That single exception is the only asymmetry in the whole site.

| page | es *(root)* | every other locale `<L>` |
| --- | --- | --- |
| home | `index.html` | `<L>/index.html` |
| who we are | `nosotros.html` | `<L>/about.html` |
| products | `productos.html` | `<L>/products.html` |
| processes | `procesos.html` | `<L>/processes.html` |
| contact | `contacto.html` | `<L>/contact.html` |

Relative paths from a non-Spanish page (e.g. `ja/products.html`):

| target | href |
| --- | --- |
| assets | `../assets/…` |
| sibling page | `about.html` |
| same page in Spanish | `../productos.html` |
| same page in another locale | `../fr/products.html` |

From a Spanish (root) page: assets are `assets/…`, siblings are bare filenames, other locales are
`en/products.html`, `ja/products.html`, and so on.

### hreflang block — identical on all seven versions of a given page

Every page carries all seven alternates plus `x-default` pointing at the Spanish version. Example,
as it appears on `ja/products.html`:

```html
<link rel="alternate" hreflang="es-MX"   href="../productos.html">
<link rel="alternate" hreflang="en"      href="../en/products.html">
<link rel="alternate" hreflang="it"      href="../it/products.html">
<link rel="alternate" hreflang="fr"      href="../fr/products.html">
<link rel="alternate" hreflang="ja"      href="products.html">
<link rel="alternate" hreflang="zh-Hans" href="../zh/products.html">
<link rel="alternate" hreflang="ko"      href="../ko/products.html">
<link rel="alternate" hreflang="x-default" href="../productos.html">
```

## 2. The language switcher

Replaces the two-way ES/EN toggle. It is a **disclosure menu**, not a `<select>`, and it works
without JavaScript in the sense that all seven links are real `<a href>` elements present in the
markup — script only shows and hides the panel.

```html
<div class="nv-lang">
  <button class="nv-lang__toggle" aria-expanded="false" aria-controls="nv-lang-panel"
          aria-label="Idioma · Language">
    <span class="nv-lang__current">Español</span>
    <svg …chevron, 1.25 stroke, 14px…></svg>
  </button>
  <ul class="nv-lang__panel" id="nv-lang-panel" hidden>
    <li><span class="nv-lang__item is-current" aria-current="true" lang="es-MX">Español</span></li>
    <li><a class="nv-lang__item" lang="en"      hreflang="en"      href="en/products.html">English</a></li>
    <li><a class="nv-lang__item" lang="it"      hreflang="it"      href="it/products.html">Italiano</a></li>
    <li><a class="nv-lang__item" lang="fr"      hreflang="fr"      href="fr/products.html">Français</a></li>
    <li><a class="nv-lang__item" lang="ja"      hreflang="ja"      href="ja/products.html">日本語</a></li>
    <li><a class="nv-lang__item" lang="zh-Hans" hreflang="zh-Hans" href="zh/products.html">中文</a></li>
    <li><a class="nv-lang__item" lang="ko"      hreflang="ko"      href="ko/products.html">한국어</a></li>
  </ul>
</div>
```

Rules:
- Each link points at **the current page** in that locale, never at a home page.
- The current locale is a `<span>`, not a link, and carries `aria-current="true"`.
- Every item carries its own `lang` attribute so the browser picks the right font and hyphenation
  even while the surrounding page is in another language. This is what stops 日本語 and 한국어 from
  rendering in a mismatched fallback face inside a Spanish page.
- Design: square panel, `--surface-card` ground, 1 px hairline, `--shadow-overlay`, no radius. Items
  are `--fs-body-sm` Archivo (CJK endonyms fall through to the CJK stack), 44 px tall, 4 % ink wash
  on hover. The toggle is a `.nv-btn--ghost` with the chevron rotating 180° over `--dur-fast`.
- Behaviour in `site.js`: click toggles, Esc closes and returns focus to the toggle, click outside
  closes, ↑/↓ move between items, Home/End jump to the ends.
- On mobile the panel is not a dropdown — the seven links are rendered as a labelled block at the
  bottom of the nav drawer.

## 3. Type for three scripts

Bodoni Moda, Archivo and Pinyon Script carry no CJK glyphs. Rather than ship megabytes of Noto, the
CJK locales fall through to the best system faces, with the Latin faces kept **first** in every
stack so the wordmark, the numerals, the g/m² units and the company name still set in Bodoni and
Archivo inside a Japanese, Chinese or Korean sentence.

Add to `site.css` (tokens stay untouched):

```css
:root{
  --font-display-ja:"Bodoni Moda","Yu Mincho","YuMincho","Hiragino Mincho ProN","Noto Serif JP","MS Mincho",serif;
  --font-ui-ja:"Archivo","Yu Gothic","YuGothic","Hiragino Sans","Noto Sans JP","Meiryo",sans-serif;
  --font-display-zh:"Bodoni Moda","Songti SC","SimSun","Noto Serif SC","Source Han Serif SC",serif;
  --font-ui-zh:"Archivo","PingFang SC","Microsoft YaHei","Noto Sans SC","Source Han Sans SC",sans-serif;
  --font-display-ko:"Bodoni Moda","Nanum Myeongjo","Batang","Noto Serif KR","Source Han Serif K",serif;
  --font-ui-ko:"Archivo","Malgun Gothic","Apple SD Gothic Neo","Noto Sans KR",sans-serif;
}
:lang(ja){--font-display:var(--font-display-ja);--font-ui:var(--font-ui-ja);}
:lang(zh-Hans),:lang(zh){--font-display:var(--font-display-zh);--font-ui:var(--font-ui-zh);}
:lang(ko){--font-display:var(--font-display-ko);--font-ui:var(--font-ui-ko);}
```

Because the components all read `var(--font-display)` / `var(--font-ui)`, redefining those two
custom properties under `:lang()` re-skins the entire page with no other change.

Then the per-script typographic corrections, also keyed on `:lang()`:

| what | Latin (es/en/it/fr) | CJK (ja/zh/ko) |
| --- | --- | --- |
| body line-height | `1.7` | `1.9` — CJK needs more leading |
| display line-height | `1.05` | `1.35` — Bodoni's tight leading crushes kanji |
| display letter-spacing | `-.01em` | `.02em` — CJK wants air, not tightening |
| micro-label | `text-transform:uppercase; letter-spacing:.24em` | `text-transform:none; letter-spacing:.12em` — there is no uppercase in CJK and `.24em` shreds a kanji run |
| pull quote | Bodoni **italic** | upright, `font-style:normal` — CJK has no true italic and the browser will synthesise an ugly oblique. Keep the khaki hanging rule as the marker instead |
| headline measure | `max-width: 18ch` | `max-width: 15em` — `ch` is calibrated to `0` and is meaningless for full-width glyphs |
| wrapping | default | `line-break: strict; word-break: normal; overflow-wrap: anywhere` |
| numerals | mono, unchanged | mono, unchanged — never let a CJK face take the digits |

Korean additionally wants `word-break: keep-all` so 어절 are not split mid-word.

The hero `<h1>` clamp drops one step for CJK: `clamp(32px, 5vw, 60px)` instead of
`clamp(40px, 6vw, 76px)`.

## 6. What never gets translated

- **Company names**, in every language, exactly: `Novalan, S.A. de C.V.` and
  `San Ildefonso Fábrica de Tejidos de Lana, S.A. de C.V.` No transliteration, no gloss. In CJK
  pages they may be followed by a short parenthetical only if CONTENT.md supports it — it does not,
  so do not add one.
- **The address.** `Carr. Tulancingo-Huapalcalco #1510 / Col. Caltengo / Tulancingo, Hidalgo. México
  / C.P.: 43626` stays in Spanish in all seven versions, because that is what has to be written on
  an envelope. Only the *label* above it is translated. Same for the phone numbers, the email
  address and the coordinates.
- **The wordmark and its tagline.** *Weaving beauty since 1983* is artwork. Never re-typeset it,
  never translate it, always the supplied PNG.
- **`g/m²`, `1847`, `1977`, `1983`, `170`, `C.P. 43626`** and every other numeral — mono type,
  Western digits, in all seven languages.
