# Slide templates

Six 1280×720 slides, plain HTML on the token layer (no bundle needed).

| File | Use |
| --- | --- |
| `title.html` | Opening slide — ink woven ground, light wordmark, season label |
| `section.html` | Section divider — khaki ground, numbered, italic subtitle |
| `statement.html` | One sentence between two hairlines |
| `comparison.html` | Two columns split by a vertical hairline (menudeo vs mayoreo) |
| `data.html` | Four display-serif figures over micro-labels |
| `collection.html` | Colourway strip with names + lot codes |

Rules: text never below 24 px, one khaki accent per slide, mono for every number, wordmark artwork bottom-right on closing/summary slides. Duplicate a file and replace copy — do not restyle.
