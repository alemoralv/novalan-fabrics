Container for products, specs, orders. Flat by default — depth is a hover affordance only.

```jsx
<Card interactive padding="none">
  <div className="nv-weave-canvas" style={{height:260}} />
  <div style={{padding:"20px 22px 24px"}}><h4>Camisa Ombré</h4></div>
</Card>
```

Use `ink` for a single dark editorial block per page; never stack multiple ink cards.
