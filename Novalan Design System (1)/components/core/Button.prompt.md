The action control. One primary per view; everything else is secondary, ghost or link.

```jsx
<Button variant="primary">Agregar a la bolsa</Button>
<Button variant="secondary" iconRight={<Icon name="arrow-right" />}>Ver colección</Button>
<Button variant="link" size="sm">Guía de cuidado</Button>
```

Labels are uppercase Spanish, 1–3 words, no ending punctuation. Hover on primary shifts black → walnut; press drops opacity to .86. Never round the corners.
