Intentional addition — every Novalan product carries measurable specs, so this pattern repeats across shop, catalogue and ops.

```jsx
<SpecList items={[
  {label:"Composición", value:"100% lino", mono:false},
  {label:"Gramaje", value:"240 g/m²"},
  {label:"Ancho", value:"150 cm"}
]} />
```

Values default to mono; pass `mono:false` for words.
