Line icon wrapper. Requires the Lucide UMD script on the page: `<script src="https://unpkg.com/lucide@0.544.0/dist/umd/lucide.js"></script>`.

```jsx
<Icon name="arrow-right" size={16} />
<Icon name="scissors" size={20} label="Corte a medida" />
```

Stroke weight is always 1.25 so icons read as hairlines next to 1px rules. Never fill icons; never mix two weights on one screen.
